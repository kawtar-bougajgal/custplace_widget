
# Custplace Reviews Widget

An intelligent, responsive customer reviews widget designed to display, filter, and summarize user feedback on web pages.

Built with React, Tailwind CSS, and Google Gemini API, with local development powered by Vercel CLI.

## Features

- AI-powered review summaries generated from customer feedback using Google Gemini API
- Interactive review filtering and rating display
- Responsive layout across mobile, tablet, and desktop screens
- Lightweight widget architecture built with Vite

## Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5
- **Styling:** Tailwind CSS, PostCSS
- **Build & Development:** Vite, Vercel CLI
- **AI Integration:** Google Gemini API

## Getting Started

### Requirements

- Node.js 18+
- npm
- Vercel CLI

### Installation

Clone the repository:

```bash
git clone https://github.com/kawtar-bougajgal/custplace_widget.git
```

Navigate to the project directory:

```bash
cd custplace_widget
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env` file in the root directory and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your actual API key.

### Run Locally

Start the local development server:

```bash
vercel dev
```
